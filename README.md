## Key results

- **Calibration.** A five-segment BATES model of the Cesaroni L1395 reproduces its certified thrust curve to 1.8% RMS and its total impulse to 0.3%. The characteristic velocity $c^*$ is identified to ±0.1%.
- **Flight validation.** Flown in RocketPy with the launch-day ERA5 atmosphere, the calibrated motor reaches 1317 m against a measured apogee of 1320 m (−0.24% at $n = 0.40$; within 0.5% across the calibrated family).
- **Sensitivity.** Over 5,120 coupled motor and flight simulations, apogee varies with a standard deviation of 37.5 m. Motor inputs carry about 80% of that variance; grain temperature alone has a total-order index of 0.53.
- **Calibration ambiguity is harmless.** The pressure exponent, the one parameter the certified curve cannot pin down, contributes under 1% of apogee variance.
- **Verification.** Every solver is checked against a closed form, a conservation law or an analytic benchmark; 41 tests run in CI.

## Background and motivation

Trajectory tools usually treat the motor as a fixed thrust curve. Real motors scatter: a cold grain burns more slowly than a hot one, propellant batches differ, and nozzle throats erode. This project replaces the fixed curve with a physical motor model so that those uncertainties can be propagated through to the flight, and asks which of them matter.

The test case is the Notre Dame Rocket Team (NDRT) launch of 23 February 2020, RocketPy's published validation case [2]. Its motor, a Cesaroni L1395, has a certified static-test thrust curve but proprietary propellant data, so the burn-rate law and $c^*$ are calibrated, not predicted.

```mermaid
    B --> F["RocketPy 6-DOF<br/>ERA5 atmosphere"]
    F --> S["Sobol indices"]
    F --> V["Measured flight<br/>validation"]
```

### Governing equations

**Burnback.** For uniform regression, the burning surface at burnt web $w$ is the $w$-level set of the signed distance $\phi$ to the initial port boundary [6, 10]. A segment of length $L$ with $n_e$ burning end faces has burning area

$$A_b(w) = S(w)(L - n_e w) + n_e\left(A_{case} - A_p(w)\right)$$

where $S(w)$ is the burning perimeter and $A_p(w)$ the port area.

**Burn rate.** Saint Robert's law with exponential temperature sensitivity [3]:

$$r = a_{ref}\exp\left[\sigma_p (T_i - T_{ref})\right]\left(\frac{p}{p_{ref}}\right)^n, \qquad \sigma_p = (1 - n)\pi_K$$

**Chamber.** A zero-dimensional isothermal chamber at the delivered $c^*$, integrated from an equilibrium start to burnout:

$$\frac{V}{R T_0}\frac{\mathrm{d}p}{\mathrm{d}t} = A_b r\left(\rho_p - \frac{p}{R T_0}\right) - \frac{p A_t}{c^*}$$

**Nozzle.** Ideal thrust coefficient with an efficiency factor [9], and throat recession linear in pressure [1]:

$$F = \eta_F C_F p A_t, \qquad C_F = \sqrt{\frac{2\gamma^2}{\gamma - 1}\left(\frac{2}{\gamma + 1}\right)^{\frac{\gamma + 1}{\gamma - 1}}\left[1 - \left(\frac{p_e}{p}\right)^{\frac{\gamma - 1}{\gamma}}\right]} + \frac{A_e}{A_t}\frac{p_e - p_a}{p}$$

$$\frac{\mathrm{d}r_t}{\mathrm{d}t} = k\frac{p}{p_{ref}}$$

**Calibration.** $(a_{ref}, c^*, k)$ are found by bounded least squares on the quasi-steady part of the certified trace plus a total-impulse constraint, at each pressure exponent $n$ from 0.30 to 0.50.

**Flight.** The thrust history passes to a RocketPy `SolidMotor` with the real grain geometry and is flown in six degrees of freedom through the ERA5 reanalysis atmosphere for the launch [2, 4].

**Sensitivity.** Saltelli sampling on scrambled Sobol sequences, with the Saltelli (2010) first-order and Jansen (1999) total-order estimators and bootstrap confidence intervals [5, 8].

The quasi-1D port-flow solver and the erosive-burning models (Lenoir–Robillard, Mukunda–Paul) are documented in [`docs/THEORY.md`](docs/THEORY.md). They are verified but not needed for the short NDRT motor.

### Assumptions

- Ignition and tail-off transients are not modelled; the fit excludes the first 0.25 s.
- Combustion-gas ratio of specific heats 1.20 and thrust-coefficient efficiency 0.95 are assumed; $c^*$ absorbs the remainder.
- Grain temperature changes the burn rate only, not $c^*$.
- The airframe is RocketPy's published NDRT configuration, unchanged, including its aerodynamic model.

## Validation and verification

**Validation against measured data** (details in [`validation/README.md`](validation/README.md)):

| Comparison | Reference | Result |
|---|---|---|
| Thrust curve | Cesaroni L1395 certified static test | 1.8–2.5% RMS and +0.3 to +0.9% total impulse across $n$ = 0.30–0.50 |
| Throat erosion rate | Acharya & Kuo [1], Fig. 4a: 0.25–1.3 mm s⁻¹ at 7 MPa | Fitted 0.67–1.26 mm s⁻¹, inside the band |
| Apogee, certified curve in RocketPy | Raven altimeter, 1320.4 m | 1309.7 m (−0.81%); RocketPy publishes −0.75% [2] |
| Apogee, model motor, $n$ = 0.30 | Raven altimeter | 1314.0 m (−0.48%) |
| Apogee, model motor, $n$ = 0.40 | Raven altimeter | 1317.3 m (−0.23%) |
| Apogee, model motor, $n$ = 0.50 | Raven altimeter | 1323.3 m (+0.22%) |

The model's slightly closer match than the certified curve is within its own calibration uncertainty, so the two should be treated as equivalent. The simulated ascent runs ahead of the altimeter trace mid-flight and converges at apogee, as the flight-profile figure below shows.

**Verification against exact results** (full table in [`docs/VERIFICATION.md`](docs/VERIFICATION.md)):

| Check | Result |
|---|---|
| Distance-field burnback against exact tube perimeter | 7.2 × 10⁻⁵ maximum relative error |
| 0D burn time against closed-form progressive tube | 0.34% |
| Mass closure, 0D and quasi-1D | below 0.04% |
| Calibration recovers a known motor | 0.28% |
| Sobol estimator against analytic Ishigami indices | 9 × 10⁻⁴ maximum absolute error |

## Quick start

```bash
git clone https://github.com/adamcw169/SRM-motor-to-flight.git
cd SRM-motor-to-flight
pip install -r requirements.txt
python validation/ndrt/fetch_data.py
```

The last command downloads the NDRT thrust curve, altimeter record and ERA5 file from the RocketPy repository at a pinned commit; they are not redistributed here. `pip install -e ".[dev,flight]"` is equivalent to the requirements file.

Reproduce every figure, the animation and the key-numbers table (about 90 seconds):

```bash
python scripts/make_figures.py
```

Run the tests and the underlying studies:

```bash
pytest                                        # 41 tests: verification and flight validation
python examples/03_ndrt_calibration.py        # calibration
python examples/04_ndrt_flight_validation.py  # flight validation
python examples/05_ndrt_flight_sobol.py       # 5,120 flights, about 20 minutes
```

```python
from srmflight.cases import ndrt2020 as nd

cal = nd.Calibration.load("validation/ndrt/calibration.json")
motor = nd.l1395(**cal.at(0.40), T_grain=273.15 - 20)   # a cold grain
print(motor.summary())                                    # peak pressure, impulse, burn time
flight = nd.fly(nd.motor_from_result(motor), nd.environment("validation/ndrt/data"))
print(flight.apogee - nd.ELEVATION)
```

## Limitations and future work

- **Transients.** Ignition and tail-off are not modelled, so the ignition spike in the certified curve is not reproduced.
- **Calibrated, not predicted.** The L1395 propellant is proprietary; its burn-rate law and $c^*$ come from the fit. A motor with published propellant data would allow a predictive test.
- **Temperature model.** Grain temperature changes the burn rate only, not $c^*$.
- **Temperature envelope.** The −45 to +60 °C range is a qualification-style stress range, not a launch-day spread, so the sensitivity ranking reflects that choice.
- **Airframe.** RocketPy's published NDRT configuration and aerodynamic model are used unchanged. RocketPy reports a −0.18 calibre static margin at ignition for it, where the team measured +2.9.
- **One flight.** Validation rests on a single launch and on apogee; more flights and measured chamber pressure would strengthen it.
